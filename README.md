# 검·인정 교과용도서 선정 문서 작성 웹앱

「검‧인정 교과용도서 선정 계획(안)」의 서식1(선정 평가표)·서식2(평가 총괄표)·서식3(추천 의견서)을
자동 초안 생성 → 인라인 편집 → 인쇄·PDF 저장 → 과목별 자동 집계까지 처리하는 웹앱입니다.
개발 계획서: [교과서선정_문서작성_웹앱_개발계획.md](./교과서선정_문서작성_웹앱_개발계획.md)

- **배포 주소**: https://dacisosl.github.io/choice/
- `main` 브랜치에 push 하면 GitHub Actions가 자동으로 빌드·배포합니다.

## 한눈에 보는 구조

**로그인 없이 쓰고, 평가 자료는 서버에 올라가지 않습니다.**

```
위원 선생님                              총괄 작성 선생님
  과목·출판사·순위 입력                     받은 PDF 올리기
  → 서식1·서식3 초안 → 편집               → 위원명·출판사·점수 자동 추출
  → [PDF로 저장] ───── 메일·메신저 ─────▶  → 서식2 총괄표 집계 + 공식 서식3
                                          → 인쇄·PDF 저장
```

| 대상 | 가입 | 하는 일 |
|---|---|---|
| **위원 교사** | 필요 없음 | 서식1·개인 서식3 작성, 인쇄·PDF 저장 |
| **총괄 작성 교사** | 필요 없음 | 위원들의 서식1 PDF를 올려 서식2·공식 서식3 작성 |

- **로그인도 서버도 없습니다.** 계정, 데이터베이스, 제출 기능이 모두 없습니다.
- 과목·출판사 목록은 앱과 함께 배포되는 파일 [`public/catalog.json`](./public/catalog.json) 에서 옵니다. 선생님은 목록에서 고르기만 하면 됩니다.
- 작성한 평가표·총괄표는 **그 컴퓨터의 브라우저에만** 저장됩니다.
- 브라우저 자료를 지우면 작성 중인 문서도 사라집니다. [JSON 내보내기]로 백업하세요.
- 총괄표는 **평가표 PDF 만** 올려서 만듭니다. 위원별 파일을 따로 올려도, 여러 위원 평가표를 한 파일로 합쳐 올려도 되고, 평가표+의견서가 한 파일에 있어도 됩니다. 의견서만 따로 온 파일은 같은 이름의 위원에게 붙입니다. 빈 장이 끼어 있어도 건너뜁니다.

## 화면

| 화면 | 내용 |
|---|---|
| 서류 작성 | ① 중/고 선택 → 과목 검색(초성도 됨) → 출판사 자동 → 순위를 넣으면 선정 평가표가 바로 생성(셀 편집, 배점 초과·순위 뒤바뀜 차단) → ② 추천 의견서 → ③ 평가표·추천 의견서를 **각각** 인쇄·PDF 저장(이 단계에서도 편집 가능) |
| 총괄표 | ① 작성자·과목 입력 + 위원 PDF·JSON 올리기 → [총괄표 생성하기] → ② 평가 총괄표·추천 의견서 확인·편집 → ③ 인쇄·PDF·JSON 저장 |
| 설정 | 교과서 자료 현황·다시 불러오기, 선정 과목 관리(목록 붙여넣기·CSV·개별 추가/수정/삭제), 과목별 출판사 관리, 평가기준 |

### 의견 작성

서식의 **의견 칸을 클릭**하면 창이 열립니다. 그 안에서 핵심의견을 고르고 → [의견 생성] → 문장을 다듬고 → [적용]까지 한 번에 합니다.
고른 핵심의견은 문서에 함께 저장되어 다시 열면 그대로 체크되어 있습니다.

## PDF에서 점수를 읽어 오는 방식

총괄 화면은 올린 PDF의 **글자(텍스트 레이어)** 를 읽어 표를 복원합니다.

1. 위원이 [인쇄 / PDF 저장] → 인쇄 창의 대상에서 **PDF로 저장**을 고르면 글자가 그대로 들어간 PDF가 만들어집니다. (평가표는 가로, 추천 의견서는 세로로 자동 출력)
2. 총괄 화면에서 그 PDF들을 올리면 `합계` 줄의 숫자 위치를 기준으로 출판사 열을 찾아 위원명·과목·출판사·항목 점수·총점·종합의견을 복원합니다.
3. 항목 점수의 합과 표의 합계가 다르면 경고를 표시하고 합계를 그대로 씁니다.

예비 수단:

- **스캔·사진 PDF** — 글자 정보가 없으면 그림에서 글자를 읽습니다(OCR, `tesseract.js`). 시간이 오래 걸리고 숫자가 틀릴 수 있어 표에서 확인이 필요합니다.
- **JSON 파일** — 위원 화면의 [파일로 저장(JSON)]으로 만든 파일을 올리면 가장 정확합니다.
- **직접 추가** — 위원 이름만 넣고 총괄표 셀에 점수를 직접 입력할 수 있습니다.

## 교과서 자료 (public/catalog.json)

과목별 교과서(출판사) 목록을 담는 파일 하나입니다. 이 파일만 채워 두면 모든 선생님 화면의 과목·출판사가 채워집니다.

```json
{
  "updatedAt": "2026-09-13",
  "year": 2027,
  "subjects": [
    { "name": "세계사", "gradeGroup": "3", "subjectGroup": "사회",
      "publishers": ["비상교육", "천재교육", "미래엔"] },
    { "name": "확률과 통계", "gradeGroup": "3", "subjectGroup": "수학",
      "publishers": [{ "name": "비상교육", "price": "12,000" }, { "name": "동아출판" }] }
  ]
}
```

- `name` 과 `publishers` 만 필수입니다. `school`(중/고)·`gradeGroup`(1·2/3)·`subjectGroup`(교과)을 적으면 검색·필터에 쓰입니다. `id` 는 적지 않으면 자동 생성됩니다.
- **교과서목록 엑셀에서 바로 만들기**: 교과서민원바로처리센터 등에서 내려받은 `교과서목록.xls`(실제로는 HTML 표)를 넣으면 이 파일을 만들어 줍니다.
  ```bash
  node scripts/catalog-from-xls.mjs 중1-2.xls 중3.xls 고1-2.xls 고3.xls
  ```
  학교(중1~2·중3·고1~2…)·교과(군)·도서명·발행사를 읽어 과목별 출판사 목록으로 묶습니다. 사이트 내려받기가 300행에서 잘리는 경우가 있으니 교과별로 나눠 받아 모두 넣어 주세요.
- `updatedAt` 을 바꿔서 배포하면, 각 컴퓨터가 다음 접속 때 새 목록을 받아 갑니다. (설정 › 교과서 자료 › [자료 다시 불러오기] 로 즉시 받을 수도 있습니다.)
- 선생님이 **설정에서 직접 넣은 과목·출판사는 지워지지 않습니다.** 자료에서 온 항목만 새로 채워집니다.
- 자료에 없는 과목은 작성 화면에서 **직접 입력**해 바로 쓸 수 있습니다.

### 저장되는 곳

| 무엇 | 어디에 |
|---|---|
| 평가표·총괄표·점수·의견 | 그 컴퓨터의 브라우저(localStorage) |
| 과목·출판사·평가기준·의견 선택지 | 같은 컴퓨터. 과목·출판사는 `catalog.json` 으로 채워집니다 |
| 서버 | **없음** (GitHub Pages 정적 배포뿐) |

개인정보를 수집하지 않습니다. 문서에 적는 이름은 인쇄물에만 들어가며 어디로도 전송되지 않습니다.

## 의견 문장 만들기

핵심의견을 고르고 [의견 생성]을 누르면 문장을 만들어 줍니다. **바깥 서비스(AI API)를 부르지 않고** 앱 안의 규칙으로 만들기 때문에 인터넷이 느려도, 키가 없어도 그대로 동작합니다. 만들어진 문장은 그 자리에서 고쳐 쓸 수 있습니다.

## 운영 순서 (권장)

1. 관리자가 `public/catalog.json` 에 올해 과목·출판사를 채워 배포합니다.
2. 위원 선생님들이 서식1·서식3을 작성하고 **PDF로 저장**해 총괄 선생님께 전달합니다.
3. 총괄 선생님이 그 **PDF들을 올려** 서식2·서식3을 만들고 확인·인쇄합니다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173/choice/
npm run build    # dist/
```

React 18 + Vite + TypeScript. 외부 UI 라이브러리 없이 `src/styles.css` 한 파일로 화면·인쇄(@media print, 서식1 A4 가로 / 서식2·3 세로) 스타일을 관리합니다.

```
src/
  seed.ts                 과목 목록·기본 평가기준·의견 선택지 초기 데이터
  lib/scoring.ts          순위→점수 초안, 합계·평균·순위(동점) 계산
  lib/opinionText.ts      고른 핵심의견 → 의견 문장 (바깥 서비스 없음)
  lib/form1Parse.ts       글자 조각 → 서식1·서식3 표 복원 (순수 함수)
  lib/pdfImport.ts        평가표 PDF 읽기 (텍스트 레이어 → 안 되면 OCR)
  store/storage.ts        이 컴퓨터 저장(localStorage) + catalog.json 읽기
  store/catalog.ts        교과서 자료를 과목·출판사 목록으로 반영
  components/Form*.tsx    서식1·2·3 (화면·인쇄 공용)
  components/OpinionModal 의견 칸 클릭 → 핵심의견 선택·생성·적용
  pages/                  Start · Personal · Compile · Settings
```
